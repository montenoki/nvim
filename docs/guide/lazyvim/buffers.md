# 切换和关闭已打开的文件

> 来源：Neovim 缓冲区 + LazyVim/Bufferline 的操作入口。

## 什么时候用

同时编辑多个文件，需要来回切换或关闭暂时不用的文件时使用。缓冲区是内存中的文件内容，窗口是显示它的位置。

## 怎么用

| 模式 / 场景 | 键位或命令                 | 会发生什么                         |
| ----------- | -------------------------- | ---------------------------------- |
| 普通        | `<leader>,` / `<leader>fb` | 从列表选择已打开的缓冲区。         |
| 普通        | `Shift-h` / `Shift-l`      | 切换上一个 / 下一个缓冲区。        |
| 普通        | `<leader>bb`               | 回到上一次编辑的缓冲区。           |
| 普通        | `<leader>bd`               | 关闭当前缓冲区，尽量保留窗口布局。 |
| 普通        | `<leader>bo`               | 关闭其他缓冲区。                   |
| 普通        | `<leader>bD`               | 关闭当前缓冲区及相应窗口。         |
| 普通        | `:ls`                      | 查看缓冲区编号和状态。             |

## 跟着做一次

打开代码和配置两个文件后，用 `<leader>bb` 在它们之间来回切换。只想把配置文件从编辑现场移走，切到它后用 `<leader>bd`。

## 在你的配置里

关闭缓冲区不是删除磁盘文件。有未保存修改时，关闭动作可能要求处理修改。标签页存的是一组窗口布局，也不是一个文件；不要把这三者当成同一件事。
