# 在编辑器里运行终端命令

> 来源：Neovim 终端 + LazyVim/Snacks 入口。

## 什么时候用

临时跑测试、执行脚本或查看 Git 状态，不想离开当前编辑现场时使用。

## 怎么用

| 模式 / 场景 | 键位或命令              | 会发生什么                           |
| ----------- | ----------------------- | ------------------------------------ |
| 普通        | `<leader>ft`            | 在项目根目录打开终端。               |
| 普通        | `<leader>fT`            | 在当前工作目录打开终端。             |
| 普通、终端  | `Ctrl-/`                | 聚焦或切换项目终端。                 |
| 终端输入    | `Ctrl-\`，接着 `Ctrl-n` | 退出终端输入模式，进入终端普通模式。 |
| 终端普通    | `i`                     | 回到终端输入。                       |
| 终端输入    | `exit`                  | 退出里面的 shell。                   |

## 跟着做一次

保存 Python 文件，按 `<leader>ft`，输入 `python main.py` 并回车。运行结束后用 `Ctrl-/` 返回编辑。需要翻看长输出时，先按 `Ctrl-\`、`Ctrl-n`，再用普通移动键。

## 在你的配置里

终端继承启动 Neovim 时的环境。项目工具由 devShell 提供时，最好先进入 devShell 再启动 Neovim；在另一个终端激活环境，不会自动改变已经运行的 Neovim。
