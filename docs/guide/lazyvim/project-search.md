# 在项目里按内容找代码

> 来源：LazyVim + fzf-lua；TODO 搜索由 todo-comments 补充。

## 什么时候用

记得函数名、报错文本或配置项，不知道它在哪个文件时使用。

## 怎么用

| 模式 / 场景 | 键位或命令                 | 会发生什么                      |
| ----------- | -------------------------- | ------------------------------- |
| 普通        | `<leader>/` / `<leader>sg` | 搜索项目根目录里的文件内容。    |
| 普通        | `<leader>sG`               | 搜索当前工作目录里的内容。      |
| 普通        | `<leader>sw`               | 搜索光标处的词。                |
| 可视        | `<leader>sw`               | 搜索选中的文字。                |
| 普通        | `<leader>sb`               | 搜索当前文件的行。              |
| 普通        | `<leader>st`               | 查找 TODO 等注释。              |
| 普通        | `]t` / `[t`                | 跳到下一条 / 上一条 TODO 注释。 |
| 选择器      | `Enter`                    | 打开文件并定位到匹配行。        |

## 跟着做一次

项目报错里有 `connection refused`：按 `<leader>/`，输入这段文字，选择匹配项后 Enter。进入代码后用 `gd` 继续追到定义；回退用 `Ctrl-o`。

## 在你的配置里

全文搜索匹配的是文本，不理解符号作用域。如果只想找某个函数真正的调用者，用 [LSP 引用](code-navigation.md) 更合适。TODO 注释不等于自动执行的任务，它只是帮助你定位记录。
