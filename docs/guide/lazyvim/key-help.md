# 不记得快捷键时找 Which-key

> 来源：LazyVim + Which-key；本地补了中文分组和说明。

## 什么时候用

知道想做哪类事情，但想不起最后一个按键时，让菜单带你找。

## 怎么用

| 模式 / 场景 | 键位或命令           | 会发生什么                         |
| ----------- | -------------------- | ---------------------------------- |
| 普通        | `<leader>`           | 按空格后稍等，查看主菜单。         |
| 普通        | `<leader>c`          | 继续查看代码相关操作。             |
| 普通        | `<leader>?`          | 查看当前缓冲区局部键位。           |
| 普通        | `Ctrl-w Space`       | 打开连续窗口操作菜单。             |
| 普通        | `<leader>sk`         | 搜索快捷键。                       |
| 普通        | `:verbose nmap <键>` | 查看普通模式某个映射及其定义来源。 |

## 跟着做一次

想整理代码但忘了格式化键：按空格，找到“代码”，接着按 `c`，在列表里找到“格式化”后按 `f`。完整组合就是 `<leader>cf`。

## 在你的配置里

`<leader>` 和 `<localleader>` 都是空格。表中的组合是依次按，不是同时按住。Which-key 中文说明不代表所有插件自己的帮助界面也已翻译；`:map` 和其他搜索仍可能显示上游英文。不同文件类型和模式的菜单不同。
