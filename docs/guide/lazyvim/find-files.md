# 按文件名打开文件

> 来源：LazyVim 的查找键位；当前主要选择器是 fzf-lua。

## 什么时候用

知道文件名的一部分，却不想一层层展开目录时使用。

## 怎么用

| 模式 / 场景 | 键位或命令                       | 会发生什么                 |
| ----------- | -------------------------------- | -------------------------- |
| 普通        | `<leader><Space>` / `<leader>ff` | 搜索项目根目录下的文件。   |
| 普通        | `<leader>fF`                     | 搜索当前工作目录下的文件。 |
| 普通        | `<leader>fr`                     | 查找最近打开过的文件。     |
| 普通        | `<leader>fc`                     | 查找 Neovim 配置文件。     |
| 选择器      | 输入名称片段，再按 `Enter`       | 筛选并打开选中的文件。     |
| 选择器      | `Esc`                            | 退出选择器。               |
| 普通        | `:pwd`                           | 查看当前工作目录。         |

## 跟着做一次

想打开 `lua/plugins/editor/surround.lua`，按 `<leader><Space>`，输入 `surround`，选中后 Enter。不用把完整路径打出来。

## 在你的配置里

“项目根目录”会由 LazyVim 根据 LSP、Git 等判断；“当前工作目录”是 `:pwd` 的结果，两者可能不同。搜索默认可能跳过被忽略的文件，找不到时先确认搜索范围，而不是断定文件不存在。
