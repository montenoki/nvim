# 恢复上次的编辑现场

> 来源：LazyVim + persistence.nvim。

## 什么时候用

重新进入项目时，希望找回之前打开的文件和分屏布局，而不是一个个重开。

## 怎么用

| 模式 / 场景 | 键位或命令   | 会发生什么               |
| ----------- | ------------ | ------------------------ |
| 普通        | `<leader>qs` | 恢复当前目录对应的会话。 |

## 跟着做一次

在项目目录启动 `nvim`，按 `<leader>qs`。如果该目录已有保存记录，会重新打开记录中的缓冲区和窗口。启动页 s 也可恢复当前项目；退出时继续自动保存。

## 在你的配置里

会话主要记住编辑布局，不是未保存文本备份，也不会把 Python 进程、终端任务、调试器或 AI 的后台请求一起恢复。保存文本仍用 `:w`；Git 版本历史也由你单独管理。
