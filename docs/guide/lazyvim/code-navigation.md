# 查定义、引用和重命名符号

> 来源：Neovim 内置 LSP + LazyVim 键位；需要语言服务器支持。

## 什么时候用

读代码时追踪函数，或者修改变量名但不想误伤普通文本时使用。

## 怎么用

| 模式 / 场景 | 键位或命令                  | 会发生什么                           |
| ----------- | --------------------------- | ------------------------------------ |
| 普通        | `gd`                        | 跳到定义。                           |
| 普通        | `gr`                        | 列出引用位置。                       |
| 普通        | `gI` / `gy`                 | 查实现 / 类型定义。                  |
| 普通        | `K`                         | 查看光标处符号的文档。               |
| 普通        | `gK`                        | 查看调用签名。                       |
| 普通        | `<leader>cr`                | 重命名当前符号及服务器识别到的引用。 |
| 普通        | `<leader>ca`                | 查看当前位置可执行的代码操作。       |
| 普通        | `<leader>ss` / `<leader>sS` | 查当前文件 / 工作区符号。            |
| 普通        | `Ctrl-o` / `Ctrl-i`         | 沿跳转历史返回 / 前进。              |

## 跟着做一次

把光标放在 `calculate_total` 上，按 `gd` 看实现，再按 `gr` 查谁调用它。确定需要改名后，用 `<leader>cr` 输入新名字；检查修改结果，再保存受影响文件。

## 在你的配置里

这些键不是“任何文件都有全部功能”。服务器未连接、项目未识别或能力不支持时，可能没有结果。Rust 中 `<leader>cR` 被语言插件用于代码操作，不能照搬其他语言“重命名文件”的解释。
