# 分屏、切换窗口和标签页

> 来源：Neovim 窗口 + LazyVim 快捷键 + window-picker。

## 什么时候用

要同时对照两个文件，或者同一文件的两个位置时使用分屏。

## 怎么用

| 模式 / 场景 | 键位或命令                          | 会发生什么                     |
| ----------- | ----------------------------------- | ------------------------------ |
| 普通        | `<leader>-`                         | 上下分屏。                     |
| 普通        | `<leader>\|`                        | 左右分屏。                     |
| 普通        | `Ctrl-h/j/k/l`                      | 切到左 / 下 / 上 / 右窗口。    |
| 普通        | `<leader>wp`                        | 用标签选择目标窗口。           |
| 普通        | `<leader>wm`                        | 临时最大化当前窗口，再按恢复。 |
| 普通        | `<leader>wd`                        | 关闭当前窗口。                 |
| 普通        | `Ctrl-w =`                          | 均分窗口尺寸。                 |
| 普通        | `<leader><Tab><Tab>`                | 新建标签页。                   |
| 普通        | `<leader><Tab>]` / `<leader><Tab>[` | 切换下一 / 上一标签页。        |

## 跟着做一次

打开实现文件，按 `<leader>|` 分屏，再在新窗口用 `<leader><Space>` 打开测试文件。用 `Ctrl-h`、`Ctrl-l` 来回切换，对照修改。

## 在你的配置里

当前 `Ctrl-h/j/k/l` 是切换焦点，不是把窗口搬到那个方向。原生 `Ctrl-w H/J/K/L` 可以把窗口移到布局边缘，但不是你 Nix 桌面的方向交换逻辑。此前规划的窗口方向移动功能尚未实现。`wM`、`uZ` 仍是最大化别名。
