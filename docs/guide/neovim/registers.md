# 寄存器与系统剪贴板

> 来源：Neovim 原生；你的 c/C、可视 p 有保护复制内容的调整。

## 什么时候用

需要连续粘贴同一段文字，或同时保存几份待复制内容时，用寄存器明确选择存放位置。

## 怎么用

| 模式 / 场景 | 键位或命令     | 会发生什么                                 |
| ----------- | -------------- | ------------------------------------------ |
| 普通        | `"ayy`         | 把当前行复制到寄存器 a。                   |
| 普通        | `"ap`          | 粘贴寄存器 a 的内容。                      |
| 普通        | `"+yy` / `"+p` | 复制一行到系统剪贴板 / 从系统剪贴板粘贴。  |
| 可视        | `"+y`          | 复制选区到系统剪贴板。                     |
| 普通        | `"_dd`         | 删除一行，不写入复制寄存器。               |
| 普通        | `:registers`   | 查看寄存器内容。                           |
| 插入        | `Ctrl-r a`     | 插入寄存器 a 的内容。                      |
| 可视        | `p`            | 用已复制内容替换选区，保留原来的复制内容。 |

## 跟着做一次

先用 `"ayy` 留住一行，再随意复制别的内容。需要那一行时按 `"ap`，它不会因为普通复制而丢失。

## 在你的配置里

桌面环境下，LazyVim 通常把普通复制与系统剪贴板同步；SSH 下策略不同。需要明确访问系统剪贴板时用 `"+`。你的 `c/C` 不覆盖之前复制的内容，普通 `d` 会写入删除寄存器。历史记录见 [Yanky](../plugins/yank-history.md)。
