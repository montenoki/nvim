# 撤销、重做和重复上次修改

> 来源：Neovim 原生；LazyVim 开启持久撤销，vim-repeat 补充插件操作。

## 什么时候用

改错了要退回，或者想对下一个对象做同样的修改时，用这三个操作。

## 怎么用

| 模式 / 场景 | 键位或命令    | 会发生什么                   |
| ----------- | ------------- | ---------------------------- |
| 普通        | `u`           | 撤销一步修改。               |
| 普通        | `Ctrl-r`      | 重做撤销掉的修改。           |
| 普通        | `.`           | 重复上一次可重复的修改。     |
| 普通        | `:earlier 5m` | 回到约五分钟前的编辑状态。   |
| 普通        | `:later 5m`   | 沿撤销历史向后移动约五分钟。 |
| 普通        | `:undolist`   | 查看撤销历史分支。           |

## 跟着做一次

先在一个词上执行 `ciwreplacement<Esc>`，移动到下一个词，再按 `.`。第二个词也会被改成 `replacement`。如果不满意，按 `u` 撤销这次修改。

## 在你的配置里

持久撤销让保存并重新打开文件后仍可能撤销之前的编辑，但它不是 Git 提交或备份。插入模式下的逗号、句号、分号会划分撤销步骤。插件动作能否用 `.` 重复，取决于插件支持；Surround 的常用修改已接入。

## 继续查

原生帮助：`:help undo`、`:help single-repeat`、`:help undo-persistence`。
