# 录制并重复一串操作

> 来源：Neovim 原生宏。

## 什么时候用

多行数据要执行同一串操作，而一个 `.` 不够表达时，可以录制宏。

## 怎么用

| 模式 / 场景  | 键位或命令 | 会发生什么                |
| ------------ | ---------- | ------------------------- |
| 普通         | `qa`       | 开始把操作录到寄存器 a。  |
| 录制中、普通 | `q`        | 停止录制。                |
| 普通         | `@a`       | 执行一次寄存器 a 里的宏。 |
| 普通         | `@@`       | 再次执行最近使用的宏。    |
| 普通         | `5@a`      | 重复执行五次。            |
| 普通         | `:reg a`   | 查看录制的内容。          |

## 跟着做一次

把几行单词逐行加上前缀：

1. 光标放在第一行，按 `qa`。
2. 按 `I` 输入 `item: `，按 `Esc`。
3. 按 `j` 移到下一行，再按 `q` 停止录制。
4. 先用 `@a` 试一行，确认正确后再用 `5@a`。

## 在你的配置里

宏会重放移动和输入，不会理解你的意图。录制时用 `0`、`^`、`A` 等相对结构定位，比记住“向右移动几格”更适合不同长度的行。寄存器 a 同时也是存文本的地方，`"ay` 会覆盖 a 中的宏。
