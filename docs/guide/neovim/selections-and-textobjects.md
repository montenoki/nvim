# 选择文本与文本对象

> 来源：Neovim 原生；中文 iw/aw 由 Jieba 适配。

## 什么时候用

修改括号、引号里的内容，或者对一段文字整体操作时，文本对象比一下一下移动更方便。

## 怎么用

| 模式 / 场景 | 键位或命令           | 会发生什么                   |
| ----------- | -------------------- | ---------------------------- |
| 普通        | `v` / `V` / `Ctrl-v` | 开始字符 / 整行 / 矩形选区。 |
| 可视        | `o`                  | 把光标切换到选区另一端。     |
| 普通        | `gv`                 | 重新选择上一次选区。         |
| 普通        | `ci"`                | 修改双引号内部，保留引号。   |
| 普通        | `di(`                | 删除圆括号内部，保留括号。   |
| 普通        | `ya(`                | 复制整个圆括号块，包含括号。 |
| 普通        | `vip` / `yip`        | 选中 / 复制段落内部。        |
| 可视        | `<` / `>`            | 向左 / 右缩进，并保留选区。  |

## 跟着做一次

原文是 `print("old value")`。光标放到字符串里，按 `ci"`，输入 `new value` 后按 `Esc`。结果是 `print("new value")`，不必重新输入引号。

## 在你的配置里

`i` 表示内部，`a` 通常表示包含边界；`iw` 是词内部，`aw` 还包含相邻空白。这里的 `i` 是跟在操作符或可视选择后面的组成部分，不是进入插入模式。不要把 Select 模式当成 Visual：片段填写位置经常使用 Select。
