# 在当前文件搜索与替换

> 来源：Neovim 原生；LazyVim 统一 n/N 的方向。

## 什么时候用

只在当前文件里找内容、替换文本，不需要打开项目级搜索界面时用。

## 怎么用

| 模式 / 场景 | 键位或命令       | 会发生什么                                  |
| ----------- | ---------------- | ------------------------------------------- |
| 普通        | `/文本`          | 向后面的内容搜索，Enter 确认。              |
| 普通        | `?文本`          | 向前面的内容搜索，Enter 确认。              |
| 普通        | `n` / `N`        | 你的配置中：向文件后方 / 前方走到搜索结果。 |
| 普通        | `*`              | 搜索光标所在单词。                          |
| 普通        | `:%s/old/new/gc` | 整个文件逐项确认替换。                      |
| 可视后输入  | `:s/old/new/gc`  | 只替换选中的行；命令行会自动带选区范围。    |
| 普通        | `:nohlsearch`    | 暂时清除搜索高亮，不删除搜索条件。          |

## 跟着做一次

执行 `:%s/timeout/retry_timeout/gc`。每次确认时按 `y` 替换、`n` 跳过、`q` 结束。末尾的 `c` 表示询问，`g` 表示同一行的全部匹配。

## 在你的配置里

搜索和替换默认使用 Vim 正则。想把特殊字符当普通文本搜索，可用 `/\V文本`。替换变量名时，优先考虑 [LSP 重命名](../lazyvim/code-navigation.md)，它能区分同名但不同含义的符号。
