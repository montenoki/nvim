# 注释代码和调整缩进

> 来源：Neovim 原生注释、缩进；LazyVim 补充操作入口并保留缩进选区。

## 什么时候用

临时停用一段代码、给代码加说明，或者把几行整体移进一个代码块时使用。

## 怎么用

| 模式 / 场景 | 键位或命令    | 会发生什么                           |
| ----------- | ------------- | ------------------------------------ |
| 普通        | `gcc`         | 注释或取消注释当前行。               |
| 可视        | `gc`          | 注释或取消注释选区覆盖的行。         |
| 普通        | `gcap`        | 对当前段落执行注释切换。             |
| 普通        | `gco` / `gcO` | 在下方 / 上方新开注释行并输入。      |
| 普通        | `>>` / `<<`   | 当前行向右 / 左缩进一级。            |
| 可视        | `>` / `<`     | 调整选中行缩进，并保留选区。         |
| 普通        | `==`          | 按当前文件的缩进规则重新缩进这一行。 |

## 跟着做一次

用 V 选中三行调试代码，按 gc 把它们注释掉；再次选中并按 gc 恢复。要把这三行放进一个条件分支，选择后按 `>` 调整缩进。

## 在你的配置里

注释符号根据文件类型决定；文件识别不对时，先用 `:set filetype?` 检查。默认缩进按四列设置，但语言文件和项目配置可以覆盖。自动缩进和 Prettier/nixfmt 这样的完整格式化是不同操作，不必每次只缩进一行都调用外部格式化器。
