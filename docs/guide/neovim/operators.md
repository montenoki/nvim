# 用动作组合修改文本

> 来源：Neovim 原生；本地调整了 c/C 和行尾键。

## 什么时候用

想改一个词、删到某个位置、复制几行时，不必先精确框选。把“做什么”和“作用到哪里”组合起来。

## 怎么用

| 模式 / 场景 | 键位或命令   | 会发生什么                                |
| ----------- | ------------ | ----------------------------------------- |
| 普通        | `dw` / `d3w` | 删除到下一个 / 第三个词首。               |
| 普通        | `dd` / `3dd` | 删除一行 / 三行。                         |
| 普通        | `yy` / `3yy` | 复制一行 / 三行。                         |
| 普通        | `ciw`        | 修改光标所在词，随后直接输入新内容。      |
| 普通        | `c$` / `C`   | 修改到原生行尾。                          |
| 普通        | `d$` / `D`   | 删除到原生行尾。                          |
| 普通        | `0` / `^`    | 到绝对行首 / 首个非空白字符。             |
| 普通、可视  | `$` / `g_`   | 到最后一个非空白字符 / 含尾随空白的行尾。 |

## 跟着做一次

原文是 `timeout = 30`，光标放在 `timeout` 中间。按 `ciw`，输入 `retry_count`，按 `Esc`，得到 `retry_count = 30`。

## 在你的配置里

你的 `c/C` 使用黑洞寄存器，改掉的文字不会挤掉之前复制的内容；`d` 仍是正常删除。`$` 和 `g_` 只在普通、可视模式交换，`d$`、`c$` 中的 `$` 仍按原生行尾理解。中文文件中的小写词动作会经过 [中文分词](../plugins/chinese-words.md)。
