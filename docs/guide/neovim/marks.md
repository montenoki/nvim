# 标记位置，随时跳回来

> 来源：Neovim 原生标记与跳转历史；LazyVim 提供标记列表入口。

## 什么时候用

读一个长文件时，要在“入口函数”和“正在排查的位置”之间反复切换，又不想记行号。

## 怎么用

| 模式 / 场景 | 键位或命令              | 会发生什么                          |
| ----------- | ----------------------- | ----------------------------------- |
| 普通        | `ma`                    | 把当前位置记为标记 a。              |
| 普通        | `'a`                    | 回到标记 a 所在行的首个非空白字符。 |
| 普通        | <code>&#96;a</code>     | 精确回到标记 a 的行和列。           |
| 普通        | `mA`                    | 设置可跨文件使用的大写标记 A。      |
| 普通        | `'A`                    | 跳到大写标记 A 对应文件和行。       |
| 普通        | `Ctrl-o` / `Ctrl-i`     | 沿跳转历史返回 / 前进。             |
| 普通        | `:marks` / `<leader>sm` | 列出标记 / 通过选择器查标记。       |

## 跟着做一次

在入口函数上按 `ma`。然后沿调用跳到别的地方，读完后按 `'a` 回入口行。要跨两个文件反复切换，可以在一个文件记 `mA`，另一个文件记 `mB`，以后用 `'A`、`'B` 跳转。

## 在你的配置里

小写标记属于当前文件，大写标记可跨文件。标记 a 与复制寄存器 a 是两套东西，互不覆盖；宏和复制内容则共享寄存器。Ctrl-i 在终端按键编码中可能与 Tab 等价，因此它在插件或片段场景里可能被其他映射接管。
