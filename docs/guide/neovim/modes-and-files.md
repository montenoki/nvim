# 进入编辑、保存和退出

> 来源：Neovim 原生；Ctrl-s 来自 LazyVim。

## 什么时候用

第一次打开文件，或者分不清现在是在输入文字还是执行命令时，先看这张。

## 怎么用

| 模式 / 场景 | 键位或命令   | 会发生什么                             |
| ----------- | ------------ | -------------------------------------- |
| 普通        | `i` / `a`    | 在光标前 / 后进入插入模式。            |
| 普通        | `I` / `A`    | 在行首非空白处 / 行尾开始输入。        |
| 普通        | `o` / `O`    | 在下方 / 上方新建一行并开始输入。      |
| 插入、可视  | `Esc`        | 回到普通模式。                         |
| 普通        | `:w`         | 保存当前文件；输入命令后按 Enter。     |
| 普通        | `:w 路径`    | 把当前内容写到指定路径。               |
| 代码编辑    | `Ctrl-s`     | 保存文件并返回普通模式。               |
| 普通        | `:q` / `:wq` | 关闭当前窗口 / 保存后关闭。            |
| 普通        | `:q!`        | 放弃该窗口关闭时需要丢弃的未保存修改。 |
| 普通        | `:qa`        | 退出全部窗口；有未保存修改时会提醒。   |

## 跟着做一次

1. 打开一个练习文件：`nvim /tmp/nvim-practice.txt`。
2. 按 `i` 输入一句话，按 `Esc`。
3. 输入 `:w`，按 Enter 保存。
4. 输入 `:q`，按 Enter 退出。

## 在你的配置里

`Esc` 还会清除搜索高亮，并结束当前片段会话。Avante 输入框里的 `Ctrl-s` 是发送请求，不是保存文件；插件窗口也可能定义自己的 `q`。
