# 在 Neovim 里检查并提交 Git 改动

> 来源：Neogit；本地入口 <leader>gn。

## 什么时候用

准备提交前，想集中检查未暂存、已暂存文件和提交内容时使用。

## 怎么用

| 模式 / 场景    | 键位或命令               | 会发生什么                           |
| -------------- | ------------------------ | ------------------------------------ |
| 普通           | `<leader>gn` / `:Neogit` | 打开 Git 状态界面。                  |
| Neogit 状态    | `Tab`                    | 展开当前文件或改动块。               |
| Neogit 状态    | `s` / `u`                | 暂存 / 取消暂存当前项。              |
| Neogit 状态    | `c`                      | 打开提交菜单，再按菜单中的提交动作。 |
| 提交消息编辑器 | `Ctrl-c Ctrl-c`          | 提交当前消息。                       |
| 提交消息编辑器 | `Ctrl-c Ctrl-k`          | 取消提交编辑。                       |
| Neogit 状态    | `?`                      | 查看当前界面帮助。                   |
| Neogit 状态    | `q`                      | 离开状态界面。                       |

## 跟着做一次

按 `<leader>gn`，用 Tab 展开文件检查差异。只对准备提交的项按 s。然后按 c 打开提交菜单，选择提交，写好消息后用 Ctrl-c Ctrl-c 完成。回状态界面确认暂存区已经清空。

## 在你的配置里

提交后代码只进入本地 Git 历史，没有自动上传远端。推送通过 Neogit 对应菜单或终端里的 Git 命令完成。不同子界面的键位不同，特别是提交消息窗口里的 Ctrl-c 组合。
