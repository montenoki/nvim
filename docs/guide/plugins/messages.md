# 找回一闪而过的错误和通知

> 来源：Noice + LazyVim 消息查看入口。

## 什么时候用

刚才出现一条消息没看清，或者操作失败却不知道报了什么时使用。

## 怎么用

| 模式 / 场景 | 键位或命令    | 会发生什么             |
| ----------- | ------------- | ---------------------- |
| 普通        | `<leader>n` | 打开全部消息文本分屏并进入窗口。 |
| 命令        | `:messages`   | 查看 Neovim 消息历史。 |

## 跟着做一次

执行一个操作后看到报错闪过，按 `<leader>n`，用 `/` 查找报错，再选择并复制完整的多行文本。普通消息、错误与通知可混排。

## 在你的配置里

“全部”指 Noice 收集的消息，包含普通消息、多行错误和 `vim.notify` 通知，不含终端等独立输出。Snacks 仍显示正常通知。消息历史用于找回输出，不会修复错误。LSP 诊断、Quickfix 和普通消息来自不同通道；代码问题优先看诊断卡片，插件启动失败则先看消息。
