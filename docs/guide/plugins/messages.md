# 找回一闪而过的错误和通知

> 来源：Noice + LazyVim 消息查看入口。

## 什么时候用

刚才出现一条消息没看清，或者操作失败却不知道报了什么时使用。

## 怎么用

| 模式 / 场景 | 键位或命令    | 会发生什么             |
| ----------- | ------------- | ---------------------- |
| 普通        | `<leader>snl` | 查看最近一条消息。     |
| 普通        | `<leader>snh` | 查看消息历史。         |
| 普通        | `<leader>sna` | 查看全部消息。         |
| 普通        | `<leader>snt` | 搜索 Noice 消息记录。  |
| 命令        | `:messages`   | 查看 Neovim 消息历史。 |

## 跟着做一次

执行一个操作后看到报错闪过，先按 `<leader>snl`；如果不是目标消息，再用 `<leader>snh` 找完整错误。排查时记录报错正文，而不只记“弹了红色提示”。

## 在你的配置里

消息历史用于找回输出，不会修复错误。LSP 诊断、Quickfix 和普通消息来自不同通道；代码问题优先看诊断卡片，插件启动失败则先看消息。
