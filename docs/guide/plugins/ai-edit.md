# 让 AI 修改选区，并决定是否应用

> 来源：Avante；编辑提示框与聊天侧栏的能力略有区别。

## 什么时候用

已经明确要改哪一段代码，希望 AI 生成具体修改，而不是只解释时使用。

## 怎么用

| 模式 / 场景         | 键位或命令   | 会发生什么                                   |
| ------------------- | ------------ | -------------------------------------------- |
| 可视                | `<leader>ae` | 针对选区打开编辑提示。                       |
| 编辑提示框          | `@`          | 补充支持的引用；这里不提供全部聊天侧栏动作。 |
| Avante 结果区、普通 | `a` / `A`    | 应用当前代码块 / 全部代码块。                |
| 冲突区域            | `co` / `ct`  | 选择原代码 / AI 代码。                       |
| 冲突区域            | `cb` / `cc`  | 保留两侧 / 采用光标所在一侧。                |
| 冲突区域            | `]x` / `[x`  | 下一个 / 上一个冲突。                        |

## 跟着做一次

用 V 选中几行重复代码，按 `<leader>ae`，说明“提取公共部分，不改变输入输出”。收到结果后先阅读，再应用需要的块。处理完冲突，保存文件并运行原来的测试。

## 在你的配置里

代码块里的 a/A 与文件树里的 a、普通模式的 a 完全不是一回事，只在对应 Avante 窗口使用。应用 AI 代码不会替你完成语义验证。上游的可视映射使用 v，也覆盖 Select 模式；这项行为仍按现状保留。
