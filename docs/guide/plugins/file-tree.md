# 沿目录找文件与选择打开位置

> 来源：Neo-tree + window-picker；LazyVim 提供入口。

## 什么时候用

不熟悉项目结构，或者要创建、移动、重命名文件时，文件树更直观。

## 怎么用

| 模式 / 场景 | 键位或命令                 | 会发生什么                          |
| ----------- | -------------------------- | ----------------------------------- |
| 普通        | `<leader>e` | 打开／关闭当前工作目录的文件树。            |
| 文件树      | `Enter`                    | 选择目标打开；只有一个目标时直接打开，无目标则新建编辑窗口。 |
| 文件树      | `v` / `s`                  | 选择目标窗口后垂直 / 水平分屏打开。 |
| 文件树      | `a`                        | 新建文件或目录，按提示填写名字。    |
| 文件树      | `r`                        | 重命名当前项。                      |
| 文件树      | `d`                        | 删除当前项，按界面确认。            |
| 文件树 | `o` / `O` | 系统程序打开文件 / 排序菜单（如 `On` 按名称排序）。 |
| 文件树      | `?`                        | 查看完整局部键位帮助。              |
| 文件树      | `q`                        | 关闭文件树。                        |

## 跟着做一次

按 `<leader>e`，用 `j/k` 找到目标文件。已有多个编辑窗口时，按 Enter 选择目标窗口；需要新开一列时按 `v`。文件打开后，树会自动收起。

## 在你的配置里

工作区已统一小写 `<cr>`，避免 Enter 被上游普通打开动作覆盖。选择器排除 Trouble、AI、调试等功能面板；启动页可直接被文件替换，完全没有可用目标时新建编辑窗口。`w`/`S` 已禁用；局部 `l` 仍是普通打开。

普通 `nvim` 的部署配置可能尚未包含这些修复；测试工作区使用 `NVIM_APPNAME=nvim-test nvim`。文件树的重命名和删除会影响磁盘文件，不是只改缓冲区名称。
