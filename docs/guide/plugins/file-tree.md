# 沿目录找文件与选择打开位置

> 来源：Neo-tree + window-picker；LazyVim 提供入口。

## 什么时候用

不熟悉项目结构，或者要创建、移动、重命名文件时，文件树更直观。

## 怎么用

| 模式 / 场景 | 键位或命令                 | 会发生什么                          |
| ----------- | -------------------------- | ----------------------------------- |
| 普通        | `<leader>e` / `<leader>fe` | 打开项目根目录的文件树。            |
| 普通        | `<leader>E`                | 打开当前工作目录的文件树。          |
| 文件树      | `w`                        | 使用上游窗口选择器打开当前项。      |
| 文件树      | `v` / `s`                  | 选择目标窗口后垂直 / 水平分屏打开。 |
| 文件树      | `a`                        | 新建文件或目录，按提示填写名字。    |
| 文件树      | `r`                        | 重命名当前项。                      |
| 文件树      | `d`                        | 删除当前项，按界面确认。            |
| 文件树      | `?`                        | 查看完整局部键位帮助。              |
| 文件树      | `q`                        | 关闭文件树。                        |

## 跟着做一次

按 `<leader>e`，用 `j/k` 找到目标文件。已有多个编辑窗口时，按 `w` 选择目标窗口；需要新开一列时按 `v`。文件打开后，树会自动收起。

## 在你的配置里

Enter 当前存在 `<CR>` 与默认 `<cr>` 的重复声明，可能直接打开，也可能走窗口选择器，因此这里先用明确的 `w`、`v`、`s`。`S` 已禁用。文件树的重命名和删除会影响磁盘文件，不是只改缓冲区名称。
