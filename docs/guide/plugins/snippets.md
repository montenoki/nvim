# 依次填写代码模板，支持嵌套

> 来源：LuaSnip + friendly-snippets + Blink。

## 什么时候用

写函数模板、条件语句或 LaTeX 分式时，想按顺序填写几个位置。

## 怎么用

| 模式 / 场景        | 键位或命令                   | 会发生什么                             |
| ------------------ | ---------------------------- | -------------------------------------- |
| 插入               | 从补全菜单选择片段并 `Enter` | 展开模板，进入第一个填写位置。         |
| 片段填写、菜单关闭 | `Tab`                        | 到下一个填写位置。                     |
| 片段填写、菜单关闭 | `Shift-Tab`                  | 回上一个填写位置。                     |
| 片段填写           | `Ctrl-Space`                 | 临时打开补全，Tab 选候选、Enter 确认。 |
| 填写完毕           | `Esc`                        | 结束当前填写并回到普通模式。           |

## 跟着做一次

假设展开的分式片段是 `\frac{分子}{分母}`：先填写分子，Tab 到分母。如果在分子中又展开了一个分式片段，可以先填内部的分子、分母，再继续 Tab 回到外层。

## 在你的配置里

嵌套能力已经用 LuaSnip 与 Blink 验证过，但“支持嵌套”不代表任意缩写都已配置成片段。具体片段由 friendly-snippets 和你的 `snippets/` 内容决定。补全菜单打开时 Tab 优先选择候选；关闭菜单后才用于跳填写位置。
