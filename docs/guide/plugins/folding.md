# 折叠代码，只看需要的部分

> 来源：Neovim 折叠操作 + nvim-ufo 提供折叠范围。

## 什么时候用

长文件里暂时只想看函数或标题结构，或者要快速检查一个收起的代码块时使用。

## 怎么用

| 模式 / 场景 | 键位或命令              | 会发生什么                               |
| ----------- | ----------------------- | ---------------------------------------- |
| 普通        | `za`                    | 切换光标处的折叠。                       |
| 普通        | `zo` / `zc`             | 展开 / 关闭光标处折叠。                  |
| 普通        | `zR` / `zM`             | 展开全部 / 关闭全部折叠。                |
| 普通        | `zK`                    | 预览光标下折叠；没有预览时尝试悬浮文档。 |
| 折叠预览    | `Ctrl-Up` / `Ctrl-Down` | 向上 / 下滚动预览内容。                  |

## 跟着做一次

打开一个有多个函数的代码文件，按 `zM` 收起折叠。移动到关心的函数，按 `zo` 展开；只想临时看里面几行，用 `zK`。读完用 `zR` 回到全部展开。

## 在你的配置里

范围优先由 LSP 提供，不可用时尝试 Tree-sitter，两者都不可用就没有自动折叠，不按缩进猜测。LICENSE、零散纯文本没有可用折叠是正常结果。折叠只隐藏显示，不删除代码。
