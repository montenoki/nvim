# 选择并确认代码补全

> 来源：Blink；候选可来自 LSP、路径、缓冲区和片段库。

## 什么时候用

输入函数、变量、路径或片段缩写时，利用候选减少输入，也查看可用名称。

## 怎么用

| 模式 / 场景    | 键位或命令                  | 会发生什么                                |
| -------------- | --------------------------- | ----------------------------------------- |
| 插入、菜单出现 | `Tab` / `Shift-Tab`         | 选择下一项 / 上一项。                     |
| 插入、已选候选 | `Enter`                     | 确认当前候选。                            |
| 插入           | `Ctrl-Space`                | 主动打开补全；继续按可切换文档显示。      |
| 插入           | `Ctrl-e`                    | 取消补全。                                |
| 补全文档可见   | `Ctrl-b` / `Ctrl-f`         | 向上 / 下滚动文档。                       |
| 插入           | 方向键、`Ctrl-n` / `Ctrl-p` | 不通过 Blink 选候选，交回原生或其他映射。 |

## 跟着做一次

在能连接 LSP 的代码文件里输入一个名称前缀。菜单出现后用 Tab 选中目标，再按 Enter。没有菜单时按 Ctrl-Space 主动请求；如果没选候选，Enter 仍可能只是换行。

## 在你的配置里

当前不预选候选，所以“看到菜单”不等于“已经选好”。填写代码片段时不会自动弹菜单；需要补全时再按 Ctrl-Space。候选是否包含项目里的类型和函数，取决于语言服务是否正常。
