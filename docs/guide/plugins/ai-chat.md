# 带着代码上下文向 AI 提问

> 来源：Avante + OpenRouter；补全引用由 blink-cmp-avante 适配。

## 什么时候用

想让 AI 解释当前代码、分析错误，或者基于指定文件讨论修改方案时使用。

## 怎么用

| 模式 / 场景 | 键位或命令                  | 会发生什么                                  |
| ----------- | --------------------------- | ------------------------------------------- |
| 普通、可视  | `<leader>aa`                | 打开提问入口；可视模式可带上选区。          |
| 普通        | `<leader>an`                | 开始新的对话。                              |
| 普通        | `<leader>at` / `<leader>af` | 切换侧栏 / 聚焦侧栏。                       |
| 输入框      | `@`、`#`、`/`               | 触发引用或命令候选；用 Tab 选、Enter 确认。 |
| 普通        | `<leader>aB`                | 把全部已打开文件加入上下文。                |
| 输入框普通  | `Enter`                     | 发送请求。                                  |
| 输入框插入  | `Ctrl-s`                    | 发送请求。                                  |
| 普通        | `<leader>aS`                | 停止生成。                                  |
| 普通        | `<leader>ah`                | 选择历史对话。                              |

## 跟着做一次

先选中一个函数，按 `<leader>aa`，输入“解释这个函数的输入输出和错误处理”。需要额外文件时，在输入框输入 `@`，选择 `@file` 再挑文件。确认上下文后发送，而不是一上来把所有缓冲区都加进去。

## 在你的配置里

当前 provider 是 OpenRouter，启动 Neovim 的环境需要 `OPENROUTER_API_KEY`。请求会发送选定上下文并使用相应 API 额度。`Ctrl-s` 在这里发送请求，不是保存。设置了 provider 不代表已经验证账号、联网和真实模型回复。
