# 快速跳到看到的位置

> 来源：Leap；本地保留跨窗口跳转，并接管 f/F/t/T。

## 什么时候用

目标就在屏幕上，逐词移动仍嫌慢，或者要跳到另一分屏里的文字时使用。

## 怎么用

| 模式 / 场景          | 键位或命令 | 会发生什么                                      |
| -------------------- | ---------- | ----------------------------------------------- |
| 普通、可视、操作等待 | `\`        | 开始跨窗口 Leap，继续输入目标字符并按提示选择。 |
| 普通、可视、操作等待 | `f` + 字符 | 向前查找这个字符。                              |
| 普通、可视、操作等待 | `F` + 字符 | 向后查找这个字符。                              |
| 普通、可视、操作等待 | `t` + 字符 | 向前到目标字符之前。                            |
| 普通、可视、操作等待 | `T` + 字符 | 向后到目标字符之后。                            |
| Leap 选择中          | `Esc`      | 取消跳转。                                      |

## 跟着做一次

要去另一分屏里的 `config`：普通模式按 `\`，依照 Leap 提示输入目标开头的字符（通常两字符），有多个候选时再按对应标签。光标会直接落到目标附近。

## 在你的配置里

`\` 是反斜杠，不是 `/`。`s/S/gs` 没有被本地配置拿来触发 Leap；`f/F/t/T` 的实现来自 Leap，而不是原生单行查找。可以组合 `dt,` 删除到逗号前，逗号保留。
