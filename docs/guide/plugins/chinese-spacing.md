# 整理中英文之间的空格

> 来源：pangu.vim；只手动执行。

## 什么时候用

文章里中英文、数字混排比较挤，想统一适当的间隔时使用。

## 怎么用

| 模式 / 场景  | 键位或命令   | 会发生什么         |
| ------------ | ------------ | ------------------ |
| 普通         | `<leader>cz` | 处理全文。         |
| 可视         | `<leader>cz` | 处理选中的整行。   |
| 命令         | `:PanguAll`  | 手动处理全文。     |
| 处理后、普通 | `u`          | 撤销这次文本调整。 |

## 跟着做一次

先用 `V` 选择一段纯正文，再按 `<leader>cz`，检查中英文和数字之间的空格变化。确认效果符合预期后，再决定要不要对全文执行。

## 在你的配置里

这个操作会实际修改文字，不只是改变显示。即使字符选区只圈住半行，当前可视映射也处理整行。Pangu 不会自动避开 Markdown 的代码块和行内代码，因此代码较多的文档优先选择正文行处理。
