# 给文字加、删、换括号或引号

> 来源：mini.surround + LazyVim Extra；Leap Extra 把前缀改成 gz。

## 什么时候用

想把一个词包进引号，把双引号换成单引号，或者去掉外层括号时使用。

## 怎么用

| 模式 / 场景 | 键位或命令              | 会发生什么                  |
| ----------- | ----------------------- | --------------------------- |
| 普通        | `gza` + 文本对象 + 符号 | 给指定文本添加包围符号。    |
| 可视        | `gza` + 符号            | 给选区添加包围符号。        |
| 普通        | `gzd` + 原符号          | 删除匹配的包围符号。        |
| 普通        | `gzr` + 原符号 + 新符号 | 替换包围符号。              |
| 普通        | `gzf` / `gzF` + 符号    | 查找右侧 / 左侧的包围符号。 |
| 等待输入时  | `Esc`                   | 取消操作。                  |

## 跟着做一次

给词语加双引号：光标放在词里，依次按 `gza`、`iw`、`"`，也就是 `gzaiw"`。
把双引号换成单引号：在字符串里依次按 `gzr`、`"`、`'`。
去掉双引号：依次按 `gzd`、`"`。

## 在你的配置里

当前前缀确实是 `gz`，不是基础 Extra 的 `gs`。中文 `iw/aw` 已做 Jieba 适配，也可以先用可视模式选好范围再加符号。看到“press output surrounding id”表示还在等你输入目标符号，不一定是报错。
