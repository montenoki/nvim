# 预览并替换多个文件的文本

> 来源：grug-far；LazyVim 使用 <leader>sr 打开。

## 什么时候用

需要批量改配置字段、URL 或固定文本，单个文件的替换不够用时使用。

## 怎么用

| 模式 / 场景    | 键位或命令                 | 会发生什么                         |
| -------------- | -------------------------- | ---------------------------------- |
| 普通           | `<leader>sr`               | 打开项目搜索替换界面。             |
| 替换界面       | 填写 `Search`、`Replace`   | 搜索并预览替换前后的内容。         |
| 替换界面       | 填写 `Files Filter` 等限制 | 缩小参与替换的文件范围。           |
| 替换界面、普通 | `<localleader>r`           | 执行 Replace，把替换写入匹配文件。 |
| 替换界面、普通 | `<localleader>c`           | 关闭这个搜索替换界面。             |

## 跟着做一次

把旧 URL 改成新 URL：打开界面，在 Search 写旧地址，在 Replace 写新地址；先用文件过滤只选文档目录。检查结果后按空格再按 r，执行替换。

## 在你的配置里

这里只有输入检索条件和预览不会替换文件，执行 Replace 才会修改多个文件。你的 localleader 也是空格。变量、函数改名优先用 LSP；普通文本替换不会识别作用域。执行后用 Git Diff 检查实际改动。
