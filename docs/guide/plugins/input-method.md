# 退出插入模式时自动切到英文

> 来源：im-select.nvim；调用系统输入法工具。

## 什么时候用

写完中文后按 Esc，接着想用 h/j/k/l、命令和快捷键，避免它们进入中文输入法。

## 怎么用

| 模式 / 场景 | 键位或命令       | 会发生什么                               |
| ----------- | ---------------- | ---------------------------------------- |
| 中文输入中  | `Esc`            | 离开插入模式时切回默认输入法。           |
| 普通        | `i` 等插入命令   | 再次进入插入模式时恢复之前的输入法状态。 |
| 命令行退出  | `Esc` 或完成命令 | 按插件默认事件恢复默认输入法。           |

## 跟着做一次

进入插入模式，切到中文并输入一句话。按 `Esc` 后尝试移动光标；再次按 `i`，观察是否恢复了刚才的中文输入状态。

## 在你的配置里

它不提供新的切换快捷键，而是跟随模式自动工作。Linux 依赖系统的 fcitx5-remote 等工具；工具缺失时当前配置保持安静。它只管理 Neovim 的模式切换，桌面窗口之间的输入法记忆由系统负责。
