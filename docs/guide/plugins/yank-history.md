# 找回之前复制过的内容

> 来源：Yanky + LazyVim；可视 p 保留本地原生替换逻辑。

## 什么时候用

刚复制了新内容，又想粘贴更早的那一段时使用，不用回原文件重新找。

## 怎么用

| 模式 / 场景    | 键位或命令  | 会发生什么                                   |
| -------------- | ----------- | -------------------------------------------- |
| 普通、可视     | `<leader>p` | 打开复制历史，选择需要的内容。               |
| 普通           | `p` / `P`   | 粘贴到光标后 / 前。                          |
| 刚粘贴后、普通 | `[y` / `]y` | 沿复制历史两个方向切换，替换刚才粘贴的内容。 |
| 普通           | `]p` / `[p` | 在下方 / 上方按行粘贴并调整缩进。            |
| 可视           | `p`         | 替换选区，同时保留之前复制的内容。           |

## 跟着做一次

先复制第一段，再复制第二段。按 `p` 粘贴第二段后，尝试 `[y` 或 `]y`，刚粘贴的位置会切换成其他历史项。记不清顺序时，直接用 `<leader>p` 查列表。

## 在你的配置里

历史切换主要用于刚完成的粘贴；做了别的编辑后，直接打开历史列表更清楚。寄存器和系统剪贴板仍然存在，Yanky 是额外的历史记录功能。
