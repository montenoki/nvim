# 按改动块检查和暂存代码

> 来源：Gitsigns；LazyVim 配置 Git 局部键位。

## 什么时候用

一个文件混着几项改动，只想提交其中一部分，或者逐块检查本次修改时使用。

## 怎么用

| 模式 / 场景          | 键位或命令    | 会发生什么                  |
| -------------------- | ------------- | --------------------------- |
| Git 文件、普通       | `]h` / `[h`   | 跳到下一个 / 上一个改动块。 |
| Git 文件、普通       | `<leader>ghp` | 预览当前改动块。            |
| Git 文件、普通或可视 | `<leader>ghs` | 暂存当前改动块或选中行。    |
| Git 文件、普通       | `<leader>ghu` | 撤销一次改动块暂存。        |
| Git 文件、普通       | `<leader>ghS` | 暂存整个文件。              |
| Git 文件、普通或可视 | `<leader>ghr` | 还原当前改动块或选中行。    |
| Git 文件、普通       | `<leader>ghb` | 查看当前行的提交归属。      |
| Git 文件、普通       | `<leader>ghd` | 查看当前文件与索引的差异。  |

## 跟着做一次

修了一个 bug，又顺手改了几处注释。用 `]h` 到 bug 对应的块，`<leader>ghp` 看清楚后用 `<leader>ghs` 暂存。之后在 Neogit 里确认暂存区只包含这项修复，再提交。

## 在你的配置里

暂存不等于提交，提交也不等于 push。`ghr` 是还原代码，不是撤销暂存；只想把内容移出暂存区时不要用它。Git 键位在插件连接到对应文件后才出现。
