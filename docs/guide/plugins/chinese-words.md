# 按中文词语移动和修改

> 来源：jieba.vim；本地扩大了文件类型范围，并适配 mini.surround。

## 什么时候用

编辑中文正文、代码里的中文注释和字符串时，想按词操作，而不是把整段中文当一大块。

## 怎么用

| 模式 / 场景          | 键位或命令      | 会发生什么                   |
| -------------------- | --------------- | ---------------------------- |
| 普通、可视、操作等待 | `w` / `b`       | 向后 / 前移动到词首。        |
| 普通、可视、操作等待 | `e` / `ge`      | 向后 / 前移动到词尾。        |
| 可视、操作等待       | `iw`            | 词语内部。                   |
| 可视、操作等待       | `aw`            | 词语及相邻空白范围。         |
| 普通                 | `ciw`           | 修改当前位置识别出的词。     |
| 普通                 | `W` / `B` / `E` | 保留原生的空白分隔大词动作。 |

## 跟着做一次

在中文注释里先用 `viw` 看看本次选中了什么，再按 `Esc` 取消选择。确认分词符合意图后，使用 `ciw` 输入新词，或者 `gzaiw"` 给它加引号。

## 在你的配置里

分词作用于整个受支持文件，不会只限于注释。已覆盖 Markdown、纯文本和多种代码、配置文件，但不是所有文件类型。词语边界来自分词模型，不一定等于你想选的范围；遇到术语时直接用可视模式更稳妥。
