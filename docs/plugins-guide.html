先掌握一条日常工作路线

找文件 → 理解 → 修改

  1. 空格 空格 找文件，空格 / 搜正文。
  2. gd 跳定义，K 看文档，空格 m 浏览结构。
  3. Tab 选择补全，Enter 接受；gzaiw" 给单词加引号。
  4. 空格 cf 格式化，空格 xx 看诊断。
  5. 空格 gn 审核 Git 变更，再暂存和提交。

写笔记 → 组织知识

  1. 打开笔记库中的 Markdown，:Obsidian quick_switch 找笔记。
  2. w/b 按中文词移动；ciw 改词。
  3. 空格 cz 整理中文排版，:PasteImage 插图。
  4. :Obsidian backlinks 查反向链接。
  5. 忘记快捷键，按空格停一下看 Which-key。

如何使用

  1. 在文本笔记中按 <leader>cz，对整个缓冲区执行 PanguAll。

遇到问题，按这个顺序检查

  1. :Lazy 确认插件是否在生效配置中；按其触发键或打开对应文件后再看 Loaded。
  2. :set filetype? 确认文件类型；:verbose nmap <Space>wm、:verbose xmap p 检查键位来源。
  3. :LspInfo 看语言服务连接；:ConformInfo 看 formatter；:checkhealth 按具体插件缩小范围。
  4. Nix 环境检查系统包/PATH/parser runtimepath；非 Nix 环境检查 Mason。不要把服务器二进制错误当成补全插件错误。
  5. 本仓库与日常部署配置可能不同；:echo stdpath('config') 查看实际配置目录。
