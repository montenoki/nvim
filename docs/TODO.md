## 按方向移动 Neovim 分屏

- [ ] 实现与桌面方向操作一致的 Neovim 窗口布局调整。

### 期望行为

通过 h/j/k/l 对应左、下、上、右，调整当前分屏的位置：

1. 对应方向存在邻居时，优先交换位置；焦点跟随原来的编辑内容。
2. 没有邻居时，尝试调整当前窗口所在的直接父分屏方向，例如上下变左右。
3. 只调整必要的局部布局，尽量保留外层布局及无关窗口的位置。
4. 已在目标方向边缘时，重复操作不应来回翻转布局。
5. 只有一个窗口时不动作；不处理浮动窗口，不跨标签页、终端复用器或显示器。
6. 应明确处理多邻居、嵌套布局、窗口局部选项以及光标和滚动位置。

### 候选方案与已知差异

- [winmove.nvim](https://github.com/MisanthropicBit/winmove.nvim)：2026-04-02 仍有兼容性维护，支持方向移动、交换和缩放。普通方向移动在边缘默认不动作，不会自动执行上述局部转向；交换通过交换缓冲区和视图实现，目标选择受光标位置影响。需验证差异或增加适配。
- [smart-splits.nvim](https://github.com/smart-splits-nvim/smart-splits.nvim)：方向交换缓冲区可用，但重点是导航和缩放，不能直接满足局部布局转向。
- 原生 `winlayout()`、`win_splitmove()` 等接口：可按需求实现，需要自行维护和测试布局规则。
